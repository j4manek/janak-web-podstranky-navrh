# Janak: ukázková varianta podstránek

Samostatná ukázka nových podstránek Topení, Kanalizace a Rekonstrukce v novém stylu (tmavý hero a kontakt, tři situace, čtyři kroky, nový formulář). Zbytek webu je stejný jako aktuální návrh.

Slouží k porovnání, než se rozhodne, kterou podobu podstránky dostanou. Web je `noindex`, formuláře zatím nikam neodesílají.

Původní návrh: https://j4manek.github.io/janak-web-navrh/
